# Mubeen Arif — Portfolio

A responsive developer portfolio built with HTML, CSS and JavaScript.

## GitHub Pages
1. Create/open a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js` and the `assets` folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/root`.
5. Save and wait for GitHub Pages to publish.

- Replace the AZAM-UL-QURAN `#` live website link with the real website URL.
